# Product Overview

## What It Is

The Scientific Knowledge Management System (SKMS) is a single, secure web application that houses CSIR-FORIG's scientific knowledge — projects, reports, publications, field data, and institutional documents — in one organised place with role-based access control, a formal submission pipeline, a permanent library, and an AI assistant that answers questions from the institute's own stored knowledge.

## Who It's For

| Role | Description |
|------|-------------|
| Researcher / Scientist | Leads or collaborates on projects, submits reports, logs field activities, publishes to library, uses AI assistant |
| CCST Student | Conducts research under supervision; student work is tracked and preserved as part of institutional memory |
| Scientific Secretary | Receives and reviews all report submissions, approves/returns/escalates, manages submission queue |
| Division Head | Oversees projects and researchers within their division; has full access to division data |
| Management / Director | Institute-wide view of all divisions, projects, reports, publications, and compliance |
| Administrator | Manages users, roles, divisions, and system settings |

## Five Core Capabilities

1. **Project Repository** — Every project gets a single record (title, lead, division, funding, dates, status, attached files). All staff can browse a directory of projects; contents are private unless the owner grants access.

2. **Report Pipeline** — Quarterly, mid-year, and annual reports are created, submitted, and tracked through a formal channel from researcher to Scientific Secretary. Every state change is timestamped and attributed.

3. **Publications Tracker** — Scholarly output (papers, theses, reports) is tracked through Draft → Submitted → In Revision → Published stages, including CCST student research.

4. **Institutional Library** — Approved reports and published documents flow into a permanent, searchable library with full-text search. The library is the institute's long-term memory.

5. **AI Assistant ("Ask SKMS")** — A plain-language Q&A interface over the library's contents. Every answer cites its source documents. Never guesses — explicitly says when it cannot answer.

## What the System Will Not Do

These are guardrails, not omissions. The system:

- Is **not** a general internet search engine or a substitute for literature review. It draws only on FORIG's own stored knowledge.
- Is only as good as what is put into the library — it rewards discipline.
- Requires an internet connection for the AI assistant. Offline, scientists can browse/search the library and save questions for later.
- Does **not** replace human judgement, peer review, or the Scientific Secretary's authority. It supports those processes.
- Does **not** offer public registration — accounts are created by Administrators only.
- Does **not** include a public-facing or unauthenticated mode beyond the login page's public stats.

## Staged Rollout Plan

1. **Pilot** — Small group of willing scientists in one division.
2. **Division-scale** — Full division plus Scientific Secretary onboarded.
3. **Institute-wide** — Open to all divisions with support available.
4. **Full adoption** — Institute-wide mandatory use, with close monitoring and adjustment.

This staged approach keeps risk low and lets the institute shape the system around how people actually work.
